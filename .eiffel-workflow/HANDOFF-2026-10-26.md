## Rules learned this session (also in memory)
- **dispose touches only its own raw fields.** It must never call another object; the collector may already have reclaimed it. → [[feedback_eiffel_dispose_own_fields_only]]
- **No side effects inside `check`.** Lean builds skip them.
- **No GPU tests or benchmarks while a long GPU job runs.**
- **After any change to a supplier library, `rm -rf` the client's EIFGENs target** (a stale build hid `Keep_mask_fill_kind`).
- **Never chain `cp backup → file` after a `;`** in a mutation run.
- **Train lean only.** Assertion builds walk dropout masks and so on through GPU mirrors.
- **The running trainer exe is locked.** Don't rebuild the `rixgpt_trainer` target while it runs.
- **GPU programs need the Vulkan SDK's Bin on PATH:** `PATH="/c/VulkanSDK/1.4.335.0/Bin:$PATH"` (for shaderc_shared.dll).
- **C library builds:** `sh build_clib.sh` in simple_vulkan; cl.exe, INCLUDE and LIB are already set in Git Bash.
