Overview

simple_tensor trains neural networks in Eiffel. Eiffel owns everything: the hot loops are C inline inside Eiffel classes, and every fast kernel has a plain-Eiffel twin that checks it. No Python or outside machine-learning library runs.

Status: milestone M1 (CPU training) is complete. The Vulkan GPU backend is milestone M3.

Quick Start

Installation

<library name="simple_tensor" location="$SIMPLE_EIFFEL/simple_tensor/simple_tensor.ecf"/>

A network learns XOR

This is the library's test test_readme_quick_start, verbatim.

local
    f: SIMPLE_TENSOR
    r: TENSOR_RANDOM
    x, y, w1, b1, w2, b2, l_loss: TENSOR
    opt: ADAMW_OPTIMIZER
    step: INTEGER
do
    create f.make
    create r.make (42)
    x := f.from_array (<<0, 0,  0, 1,  1, 0,  1, 1>>, <<4, 2>>)
    y := f.from_array (<<0, 1, 1, 0>>, <<4, 1>>)
    w1 := f.zeros (<<2, 8>>);  r.fill_normal (w1, 0.0, 1.0);  w1 := f.parameter (w1)
    b1 := f.parameter (f.zeros (<<1, 8>>))
    w2 := f.zeros (<<8, 1>>);  r.fill_normal (w2, 0.0, 0.5);  w2 := f.parameter (w2)
    b2 := f.parameter (f.zeros (<<1, 1>>))
    create opt.make (create {ARRAYED_LIST [TENSOR]}.make_from_array (<<w1, b1, w2, b2>>),
        create {CONSTANT_SCHEDULE}.make (0.05), 0.9, 0.999, 1.0e-8, 0.0)
    from step := 1 until step > 500 loop
        l_loss := ((x.matmul (w1) + b1).hyperbolic_tangent.matmul (w2) + b2).mean_squared_error (y)
        opt.step (l_loss.backward)
        step := step + 1
    end
end

Features

Autograd

34 operations, each with its backward; intermediates freed as backward runs

Optimizers

SGD and AdamW, warmup-cosine schedule, gradient clipping

Twin-checked kernels

Every C kernel is tested against a plain-Eiffel twin

safetensors

Load F32/F16/BF16 and save F32 Hugging Face weights

Language-model data

Token batcher; embeddings; causal mask; cross-entropy

SCOOP-safe

Kernels are blocking externals; the GC never waits on them
